# Clinical AI Assistant

An AI-powered Clinical Assistant built using Python, FastAPI and Azure AI Foundry.

## Features

- FastAPI REST API
- GPT-5 Mini Integration
- Azure AI Foundry
- Clinical AI Chat Endpoint

## Tech Stack

- Python 3.12
- FastAPI
- Pydantic
- OpenAI SDK
- Azure AI Foundry

## Roadmap

## Run Locally

```bash
pip install -r requirements.txt
uvicorn app.main:app --reload
```
